# Оценка эвакуации — PWA для GitHub Pages

## Публикация
1. Создайте на GitHub новый **Public** repository, например `evacuation-app`.
2. Загрузите в корень репозитория всё содержимое папки `github-pages` (не саму папку).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Через минуту GitHub покажет адрес сайта в разделе Pages.

## Установка на телефон
- iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».
- Android: открыть ссылку в Chrome → меню → «Установить приложение» или «Добавить на главный экран».

## Обновление
Замените `index.html` и при необходимости остальные файлы в репозитории. При обновлении `sw.js` рекомендуется увеличить `v1` в `CACHE_NAME` (например, `v2`), чтобы старый кэш удалился. Новая версия загрузится при следующем обращении к сайту; при офлайн-работе останется последняя закэшированная версия.

## Данные
Приложение хранит данные локально в браузере на устройстве. GitHub Pages не получает занятия и не синхронизирует их между инструкторами. Для обмена используется встроенный JSON-экспорт/импорт. Перед первым переходом со старого локального HTML экспортируйте базу JSON в старой версии, откройте опубликованный сайт и импортируйте этот JSON.

**Важно:** не очищайте данные сайта в браузере без предварительного экспорта резервной копии.
